# LAST STOP — Asset Manifest

Every asset the game loads is registered in **`src/assets/assetManifest.ts`**. To ship final art, export the file, place it next to the placeholder (or anywhere under `src/assets/`), and change the import in the manifest. No other code changes are needed. Symbols are scaled to fit their cell automatically, so any square image works.

All current art is **original placeholder vector art** made for this project, following the master style guide (palette, brass + teal glow, dark-cartoon look). Prompts for final art live in the LAST STOP Master Style Guide doc.

## Status legend

- **SVG placeholder**: original vector art in the repo, to be replaced by final illustration
- **Procedural**: drawn in code (Pixi Graphics / canvas); a painted plate can be added via `backgroundAssets`
- **Synth**: generated by `npm run audio`

## Character: Conductor Graves (`src/assets/characters/`)

Graves is a layered puppet. Final art should be delivered as separate transparent layers with the same pivots:

| Part | File | Pivot / notes |
|---|---|---|
| body | `graves_body.svg` (300×460) | anchor (0.5, 0.15); coat, smoky tail, buttons, pocket watch |
| head | `graves_head.svg` (200×220) | anchor (0.5, 0.9) at the chin; eyes are drawn in code |
| hat | `graves_hat.svg` (220×130) | anchor (0.5, 0.85), crooked |
| brows | `graves_brows.svg` | centred above the eyes |
| mouth (grin) | `graves_mouth_grin.svg` | idle / smirk |
| mouth (laugh) | `graves_mouth_laugh.svg` | win reactions |
| arm + ticket punch | `graves_arm_punch.svg` (140×260) | shoulder pivot at (40, 20) |
| presenting arm | `graves_arm_present.svg` (220×120) | shoulder pivot at (18, 30) |

Animation states (`CharacterRenderer.ts`): idle, spin, smallWin, mediumWin, bigWin, bonus, punch, train. Matching manifest entries for future full-pose art: *Graves idle, Graves win, Graves bonus, Graves train arrival*. These map to the states above and can be added as extra layers or a spritesheet.

When painted plates exist, set `backgroundAssets.main` / `.bonus` / `.tunnel` / `.fog` and load them as base layers. The design space is 1920×1080; keep the centre calm for the reels and leave space on the left for Graves.
